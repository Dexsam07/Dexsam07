### ⚡ [DexBaileys](https://github.com/Dexsam07/DexBaileys)

My own WhatsApp Web library, based on Baileys, written in TypeScript.

- Buttons, lists and cards, sticker reactions, albums, polls
- Session restore from `SESSION_ID`, database session support
- Built-in group cache, anti-delete helper, send queue

```bash
npm install github:Dexsam07/DexBaileys
```
